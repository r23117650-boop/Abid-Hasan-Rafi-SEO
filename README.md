# Abid Hasan Rafi — Personal SEO Website

A responsive, colorful, animated personal profile website for **Abid Hasan Rafi**, SEO Expert at MicroDeft and BBA student at Canadian University of Bangladesh.

## Included
- Responsive one-page website with About, SEO expertise, journey, approach, FAQ, and social links
- Animated hero illustration, reveal-on-scroll effects, and scroll progress bar
- SEO title, meta description, canonical URL placeholder, Open Graph tags
- Schema.org `ProfilePage` + `Person` JSON-LD structured data
- `robots.txt`, `sitemap.xml`, custom favicon, and 404 page
- No build tools or dependencies required; works as a static website

## Before publishing — important
1. Open `index.html`, `robots.txt`, and `sitemap.xml`.
2. Replace every `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` placeholder with your real published URL. Keep the trailing slash consistent.
3. The LinkedIn URL supplied for this project was the same Facebook URL, so it has **not** been treated as a LinkedIn profile. Add the correct LinkedIn URL to the social links and `sameAs` array if desired.
4. Replace the empty `mailto:` link with your real email address, or remove the Email link.
5. Review all profile text and skill descriptions so they accurately reflect your actual work. Add a real profile photo if you want one; do not use a placeholder as if it were you.
6. If you add an image, use an optimized WebP/AVIF or compressed JPG, provide meaningful alt text, and include the image in social metadata when appropriate.

## Publish using GitHub Pages
1. Create a new GitHub repository, for example `abid-hasan-rafi`.
2. Upload the **contents** of this ZIP (the files inside the folder) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish your site. Copy the actual live URL.
6. Replace the placeholder URL in `index.html`, `robots.txt`, and `sitemap.xml`, commit the changes, and wait for redeployment.

## Help Google discover the website
1. Open Google Search Console and add your published URL/property.
2. Verify ownership using one of the methods Search Console offers.
3. Submit your sitemap URL, such as `https://YOUR-REAL-URL/sitemap.xml`.
4. Use URL Inspection to test the homepage and request indexing.
5. Link to the website from your authentic social profiles and other relevant profiles you control.
6. Keep the profile accurate and useful. Search rankings and indexing are not guaranteed; results can take days to weeks or longer.

## SEO notes
- The target phrase **Abid Hasan Rafi** appears in the page title, primary heading, descriptive text, and structured data naturally.
- Do not add repeated or hidden keyword blocks. Prioritize genuine, useful information.
- Canonical URLs and sitemap entries must use the real public URL after deployment.
